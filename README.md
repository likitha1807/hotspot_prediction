AI Crime Hotspot Prediction System

An AI-powered web application that predicts potential crime hotspots using Machine Learning and visualizes risk levels on an interactive map.

## 📌 Project Overview

The AI Crime Hotspot Prediction System analyzes historical crime data and predicts the expected crime risk for a selected location and time.

The system helps identify areas with potentially higher crime risk and displays the results using an interactive map.

## ✨ Features

- 🤖 AI/ML-based crime prediction
- 📍 Location-based risk prediction
- 🗺️ Interactive crime hotspot map
- 📊 Historical crime data analysis
- ⏰ Time-based crime prediction
- 🚨 Risk classification
- 🌐 Flask web application
- 📈 Easy-to-understand prediction results

## 🧠 Machine Learning

The project uses Machine Learning techniques to analyze crime patterns and generate predictions.

### Input Features

- Location
- Hour
- Historical crime information
- Other relevant crime-related features

### Output

The system predicts:

- Predicted crime count
- Risk level
- Crime hotspot visualization
